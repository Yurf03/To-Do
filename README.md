# To-Do List Application

A simple command-line To-Do List application written in Python that allows users to manage their daily tasks efficiently.


## How to Run

1. Open a terminal or command prompt
2. Navigate to the project directory:
   ```
   cd "c:\Users\Jovan\OneDrive\Documents\codingtemplate\Lessons Practice\Python\Python assignments\To Do Application"
   ```
3. Run the application:
   ```
   python ToDo.py
   ```

## Usage

When you run the application, you'll be greeted with a welcome message and a menu with the following options:

### Menu Options

1. **Add Task** - Add a new task to your list
   - Enter your task description when prompted
   - The task will be added to your list

2. **View Tasks** - Display all your current tasks
   - Shows a numbered list of all tasks
   - Displays "No tasks found" if the list is empty

3. **Delete Task** - Remove a task from your list
   - Displays all current tasks with numbers
   - Enter the number of the task you want to delete
   - The task will be removed from your list

4. **Quit** - Exit the application
   - Saves your progress and closes the program
